## 检查中确认并修复的问题

1. 搜索过滤只传入已发布的 Post 会遗漏加密 Page 和隐藏发布页面。两条搜索路由现在使用完整 `allPages` 进行过滤。
2. 缓存中的新版 Notion 双层记录不能直接交给原有全文提取器。搜索路由先做记录适配，回归测试确认公开正文仍可命中，且不会产生加密正文片段。
3. 上游正文过滤没有完整处理双层记录的父节点 `content` 和根页面属性。已统一解包访问，清理受保护引用与根页面密码属性；不修改原始缓存。
4. 上游背景色逻辑依赖的配置字段在本仓库不存在，导致 CSS 颜色无效。补充浅色 `#f7f9fe` 与深色 `#18171d` 默认值，同时保留配置覆盖能力。
5. 上游新增评论按钮测试导入了本仓库已删除的组件，导致整个测试文件无法执行。已适配当前组件集合。
