# Heo 评论与目录控制

Heo 使用与共享评论组件一致的启用判断。只配置 `COMMENT_ARTALK_SERVER` 或开启 `COMMENT_NOTION_ENABLE` 时，也会显示评论区域。Notion 评论开关接受布尔 `true` 或字符串 `"true"`；未启用任何服务时不渲染空评论容器。

移动端与平板的悬浮目录使用原生按钮，可通过键盘操作，提供可访问名称和展开状态。目录以模态弹窗展示并管理焦点，支持 Escape、关闭按钮、点击遮罩或选择目录项后关闭；关闭后恢复触发按钮焦点，目录链接不进入键盘焦点顺序。切换文章、文章上锁或进入 `xl` 桌面侧栏断点时会关闭弹窗。
